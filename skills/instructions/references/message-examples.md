# Guest-message examples

These are fictional templates, not facts about a property or actions already taken. Replace bracketed fields only with host-supplied information. Do not send an incomplete template.

## Check-in message

Use only the arrival time and entry instructions the host confirms. If a code is needed, ask the host to insert it in the authorized private message rather than asking for it in chat. Do not reuse access details from a previous guest or example.

> Hi [guest name],
>
> Looking forward to your stay! Check-in starts at [confirmed time]. Your arrival instructions are in [confirmed guidebook or message location]. Let me know if you need help when you arrive.
>
> [host's preferred sign-off]

Provide a more detailed arrival guide only when the host requests one and supplies the address, parking information, lock instructions, and relevant property rules. Keep an access code out of public listing copy and public review replies.

## Reservation-change request

If the host has not decided, ask whether they can accommodate the request. Do not invent a calendar check, accept a request, or claim it was accepted.

If the host confirms willingness but the platform update is still pending:

> Hi [guest name],
>
> I can accommodate [confirmed change]. Please send the change request through Airbnb so we can update the reservation there.
>
> [host's preferred sign-off]

If the host confirms the request has already been accepted:

> Hi [guest name],
>
> Your request to change [confirmed detail] has been accepted. Your updated reservation now shows [confirmed date or detail]. Looking forward to your stay!
>
> [host's preferred sign-off]

If the host declines, give a warm and clear response based on the reason they choose to share. Do not invent a policy or include unsupported promises about refunds or future changes.

## Mixed review

Use the review itself and the host's confirmed response. Do not promise work that has not been agreed or imply that a reported issue was fixed.

> Thank you for sharing your experience. I'm glad you enjoyed [detail from the review]. I appreciate your feedback about [reported issue]. [Host-confirmed response or next step, if supplied.] Thank you for staying with us.

When no next step is confirmed, omit that sentence. Keep the reply brief and avoid private booking details, blame, incentives, review manipulation, or a request for a particular rating.
