# Package data handling

This disclosure describes the inspected Airbnb Hosting Expert package. It is not a published privacy policy or a declaration about a separate service operated by the publisher.

## Package and processing

The package contains instructions, references, listing metadata, and an icon. It contains no MCP server, executable script, hook, authentication flow, credential reader, telemetry endpoint, or publisher-operated storage implementation. The source does not route conversation content to a publisher backend.

The host application processes the conversation and any supplied files under its own privacy terms and settings. This instruction-only package cannot establish or change the host's retention, training, deletion, or access policies.

## Information used

Tasks may use listing text, public listing pages, property facts, guest-message excerpts, reviews, and the host's chosen response. These can include personal information. The instructions ask the assistant to use the minimum needed, omit unnecessary identifiers from public output, and avoid requesting credentials or property access codes.

## Tool requests and outputs

If browsing is available, the assistant can request a supplied public listing or official policy page. The website receives the request and ordinary connection metadata through the host's browser or tool. The instructions prohibit placing private guest details or access codes into search queries.

Drafts appear in the current conversation. Saving files or acting through a separately connected service requires the scope of the host's request. An authorized external action shares the chosen content with the specified service or recipient. The package includes no tool that sends a guest message or modifies a booking.

## Permissions and public publication

These are assistant instructions, not technical enforcement. The host application's enabled tools and permissions determine which actions are possible. Publisher support arrangements, public policy commitments, retention and deletion processes for any separate service, and applicable terms must be confirmed before public submission. No such commitments are invented by this disclosure.
