The icon was created using Ghibli Icon Maker's Soft Index renderer. It combines a new guesthouse-and-message illustration with the unmodified geometry of Airbnb's official logo path, retrieved from [Airbnb's public homepage](https://www.airbnb.com/). The source scripts used to render the icon are not included in this plugin package.
